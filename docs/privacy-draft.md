## Hvad vi gemmer, og hvorfor
- **Konto:** din e-mail, så du kan logge ind med en kode.
- **Profil og plan:** alder, køn, højde, vægt, hvilepuls, makspuls, mål, løb og hverdag. Bruges til at lave din
  plan, dine pulszoner og dine kostforslag.
- **Træning:** dine ture med dato, distance, tid, puls, stigning og type, din oplevede anstrengelse (RPE) og din
  ugelog. Bruges til log, belastning (ACWR) og planen.
- **Helbred:** hvilepuls, søvn og HRV dag for dag, hvis du henter dem fra Garmin eller en fil. Bruges til
  restitution og Overblik.

Uden login bliver alt på din telefon. Med login gemmes det også hos vores databaseleverandør, så det følger med på
dine enheder.

## Forbindelser du selv vælger
- **Strava:** når du forbinder, henter vi dine aktiviteter. Adgangsnøglerne ligger på vores server og kan ikke læses af
  appen. Du kan afbryde når som helst.
- **Garmin:** når du sætter din personlige Garmin-nøgle ind, henter vi hvilepuls, søvn og HRV. Nøglen ligger på vores
  server. Du kan afbryde når som helst og bør også slette nøglen i Garmin Connect.

## AI-træneren
Når du stiller et spørgsmål, sender vi spørgsmålet og et udtræk af dine tal (plan, uger, belastning, puls, søvn) til
[AI-leverandør: OpenCode Zen og den model, den bruger]. Dit navn og din e-mail sendes ikke med. [Leverandørens
opbevaring og brug af data: udfyld efter deres vilkår.]

## Position
Kun når du trykker på at finde løb nær dig. Positionen bruges i appen og gemmes ikke.

## Det gør vi ikke
Ingen reklamer, intet salg af data, ingen sporing på tværs af apps, ingen GPS-spor gemt.

## Dine rettigheder
Du kan se og eksportere dine data (Mere → Data → eksport), rette dem i appen og slette dem. **Slet konto:** Mere →
Konto → Slet min konto sletter din konto, alt i skyen og forbindelserne til Strava og Garmin. Du kan også skrive til
[kontakt-e-mail]. Du kan klage til Datatilsynet.
